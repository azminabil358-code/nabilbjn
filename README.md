# Literasi Digital - Website WordPress

Tugas mata kuliah Literasi Digital.

## Teknologi
- WordPress
- PHP
- Apache (XAMPP)
- MariaDB

## Cara Menjalankan
1. Salin folder ke C:\xampp\htdocs\literasi.
2. Buat database wp_literasi.
3. Impor database.sql.
4. Salin wp-config-sample.php menjadi wp-config.php.
5. Isi konfigurasi database.
6. Buka http://localhost/literasi.
